# Library Management

This was a fun project I spent an afternoon working on to learn C++. The project contains a library.cpp that allows a user to return and borrow books to a preset library contained in data.csv via terminal. Users are ID'd during the return process. 

This project taught me about file I/O as well classes, objects, and vectors in C++.
